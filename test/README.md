# Tailwind v4 Project Setup

## Overview
This is a simple Tailwind CSS v4 project with everything you need to get started.

## Project Structure
```
.
├── package.json          # Project dependencies and scripts
├── src/
│   └── input.css         # Source CSS with Tailwind directives
├── dist/
│   └── output.css        # Compiled CSS output
└── index.html            # HTML file using Tailwind classes
```

## Setup Instructions

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```
This watches your CSS file and rebuilds on changes.

### Step 3: Build for Production
```bash
npm run build
```
This creates a minified version for production.

## What's Included
- **Tailwind v4**: Latest version of Tailwind CSS
- **Watch Mode**: Auto-rebuild CSS as you edit HTML
- **Sample HTML**: Styled components to get you started
- **Responsive Design**: Includes responsive utilities and grid layout
